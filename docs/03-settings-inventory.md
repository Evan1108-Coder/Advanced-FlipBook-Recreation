# Settings Inventory

Settings exist at three levels:

- Global defaults on the home screen.
- Project-specific overrides in the project right panel.
- Object/tool-specific controls where needed.

## Global Settings

- Default project mode.
- Default memory behavior for new projects.
- Default source strictness.
- Default MiniMax model, aspect ratio, quality, retry count, and response format.
- Default canvas grid, snap, spacing, line style, and object sizes.
- Default toolbar position and labels.
- Default right panel width and animation speed.
- Default chat bubble size, position, and operator permissions.
- Appearance: warm/ivory theme, density, contrast, reduced motion.
- Privacy: local-only mode, clear global defaults, clear recent projects.
- Export defaults.

## Project Settings

- Project name and description.
- Default mode for this project.
- Autosave on/off.
- Version history depth.
- Delete behavior: delete descendants, detach descendants, preserve orphaned, or ask.
- Confirmation behavior.
- Project memory on/off.
- Project memory scope: generations, sources, tools, chat, user notes, backend logs.
- View/edit/clear memory.
- Canvas grid, snap, zoom speed, pan speed.
- Default object sizes.
- Auto-layout on/off.
- Connector routing style, curve, thickness, opacity, color, dotted style.
- Overlap avoidance strength.
- Toolbar order, position, snap, orientation, labels, disabled visibility.
- Right panel default section, width, min/max width, push behavior.
- Chat bubble size, compact size, expanded size, position, history retention, operator permissions.
- Flipbook click behavior, double-click behavior, default depth, style lock, hotspot visibility, hover previews, child placement.
- MiniMax image size, aspect ratio, quality, retries, prompt optimizer, draft/refined behavior.
- Sources required on/off, strictness, preferred domains, blocked domains, citation display, unsupported claim warnings.
- Animation speed, reduce motion, panel/box/line/loading animation behavior.

## Chat Settings

- Clear chat history.
- Clear chat memory.
- Use selected object automatically.
- Allow operator actions.
- Confirmation level for actions.
- Include sources in answers.
- Include backend process/audit history.
- Include project memory.
- Bubble size.
- Bubble safe-margin.
- Expanded width/height.
- Auto-open on completed tasks.

## Object Settings

- Title.
- Size and lock aspect ratio.
- Color/status marker.
- Include in memory.
- Include in exports.
- Show/hide transcript.
- Show/hide citations.
- Regeneration parameters.
- Delete protection.
